# Bilingual society ABM

An agent-based model of a bilingual society, to study **when, how fast and why
a minority language survives, shifts or erodes, and what policies change
that**.

Simulated people are born, grow up, form families, go to school, work, make
friends, move and die. They talk in the settings of everyday life: home,
school, work, shops, friends, neighbourhood, media. What they hear and say
decides what they learn and forget of each language. What they know decides
which language they use with whom, which they pass on to their children, and
which opportunities they have.

**What makes it different:**
- individual learning grounded in cognitive science, and testable with the
  same tests people take;
- social mechanisms grounded in published theory, tested first on generic
  stylised facts, and calibrated on survey data in a later phase;
- outputs in census and survey units;
- uncertainty always reported.

**Status:** Phase 0, Definition (Nov 2026). The society is designed and built
first, the learning core after. There is no code yet. Start with
[`docs/01_vision_and_scope.md`](docs/01_vision_and_scope.md). The document
